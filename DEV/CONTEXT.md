# Current context

Updated: 2026-11-23.

- **Phase:** 1 (local MVP) started; phase 0 complete. Core compiled and runnable with Go 1.27.4; the project's minimum version remains Go 1.22.
- **Exists and was verified:** `cmd/calango` (HTTP server, SQLite store and vault opened at startup; no scheduler loop yet), `internal/config` (`CALANGO_ADDR`, `CALANGO_DATA_DIR`, `CALANGO_VAULT_KEY`, `CALANGO_VAULT_KEY_FILE`), `internal/core` (agent domain, conversation and run types, approval types, routine domain: cron, quiet window, retry backoff; memory domain; ids), `internal/store` (SQLite WAL, immutable migrations 0001–0009, usage ledger, agents, node pause, conversations and runs, approvals, routines, memories, audit chain with checkpoint, vault items), `internal/audit` (chain hash and verifier), `internal/vault` (AES-256-GCM envelope, keyring and key-file bootstrap, service with set/reveal/list/delete/rotate; set, reveal and delete audit first; no HTTP yet), `internal/auth` (local API token stored as vault item `api-token`), `internal/gateway` (budget checked before calls, usage recorded after), `internal/agents` (service: CRUD, pause, monthly usage), `internal/conversations` (DMs, runs, parallel limit, stop, retry, crash recovery, memory injection; guide pending), `internal/approvals` (digest-bound requests, decisions, receipts, rules; no HTTP yet), `internal/routines` (create, pause, tick, retry, quiet window, coalescing, crash requeue; no executor, no HTTP yet), `internal/memory` (save, edit, logical delete, purge, budgeted context; no HTTP or tool yet), `internal/api` (`/healthz`, `GET /v1/audit/verify`), tests, CI with cross builds for six targets, Dockerfiles/compose, docs, OpenAPI draft, design tokens, i18n catalog and site.
- **Does not exist yet:** provider and harness (waiting on D3), guide/steer, WebSocket `/v1/events`, HTTP routes for conversations, runs and routines, the rest of the data model (connectors, ...), QR pairing, desktop, mobile, Cloud, embedded transport, ADE and browser.
